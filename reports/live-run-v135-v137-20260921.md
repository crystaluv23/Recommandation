## 终止依据：结转上限与实测失败率的数学不相容

V137 真实账目：24 案中 c01 失败 ~7 次（结转 2 后仍 5 次死亡）、c02 失败 ~5 次。观测单案失败率 **p ≈ 0.25–0.30**（initialize/纠正链耗尽）。在 cap=2/24 下：

| 单案失败率 | 一轮存活概率（两槽任一 viable） |
| --- | --- |
| 10% | 56% |
| 15% | 28% |
| **25%（实测）** | **4%** |
| 30% | 1% |

即当前模型在该评估案例面上的能力，与"每候选 ≤2 例弃权"的组合在统计上不可行——不是链路问题，是**研究面配置问题**。V130 能通过是当时案例面较易（0 例 initialize 死亡）；V131 后案例面（2025H2 深度案例）显著更难。
