## Cause and bounded change

The old overlap check discarded object attachment and disclosure-window tokens.
Different explicit objects sharing a facet, and complementary disclosure windows
for one object, consequently looked like duplicate coverage. A separate cosmetic
progress gate had the same problem. Fixing only the overlap helper could not
preserve the full native selection.

The owning spec was extended before the candidate implementation. One private
literal partition proof now serves both routing gates. It requires complete
ordered target arms with explicit different objects, or the exact complementary
disclosure windows established by the target. Different window lengths,
incomplete date ranges, delivery times, unrelated sentences, negations and
scrambled subject words supply no proof. An answered arm cannot exempt an
additional retained-facet claim. Ambiguous syntax keeps the existing guard.

Actual Reflect consumption uses the same structural distinction only with an
actual partial disposition, current newly adopted evidence, exact target
ownership, valid PIT and the exact residual mirror. A selection's structural
split does not establish that an answer exists. Unanswered/untargeted occurrences,
unavailable or absent results, wrong owners and changed mirrors retain their
existing obligations. Public schemas, measurement definitions, budgets, typed
repair permissions and fallback remain unchanged.
