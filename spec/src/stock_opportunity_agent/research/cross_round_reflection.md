# Cross-round Same-case Reflection

## Purpose

Derive source-bound retrospective comparisons from caller-authorized committed
Fast records. This pure module owns observation identity and pairing, not file
access, LLM calls, scoring, Registry admission or publication.

## Contract

- An observation binds an opaque issuer/time case key, outcome-contract hash,
  origin contract, exact Plan-record and trajectory hashes/locator, prediction,
  canonical context/Plan hashes and the anonymous case reflection original.
  Content hashes are checked on import. Complete source units are never clipped.
- Align the same issuer and prediction time under the same fixed prediction
  semantics and exact ground-truth contract. Different dates/contracts never
  form a pair. Compare adjacent distinct observations in committed order,
  deduplicating immutable originals before pairing; do not enumerate all pairs.
- Preserve direction reversals, magnitude changes and technical execution
  changes. A technical exclusion is a diagnostic, not a research judgment.
  Input comparison covers canonical context/Plan only; provider prompt/model
  equivalence and causality remain explicitly unestablished.
- Paired observations and deterministic changes are immutable feedback units.
  The entry Slow role adds a distinct `cross_round` reflection layer, with
  fact/hypothesis/action and complete paired indexes. Causes remain hypotheses;
  prompt/Plan sensitivity routes to research-method improvement, measurable
  PIT evidence relationships may become Mining/Update hypotheses.
- The workspace selects only pointer-reachable local records and exact frozen
  observation derivatives supplied by an authorized history/bootstrap manifest.
  No directory scan or ancestry inference grants access. Existing manifests
  without these derivatives remain readable without invented observations.
- The frozen Slow input retains every comparison. Bounded reflection reserves
  a slot for a pending comparison while retaining other feedback slots; failure
  consumes no comparison. Runtime binds the layer after validated model output.
  Mining's full scoped index contains paired originals and completed authored
  reflections; initial context is bounded and every omitted unit is discoverable.
- No blind prediction, score, label, fixed evaluation denominator or historical
  artifact is modified. Replay proves wiring/provenance only, not useful lessons
  or improved prediction.

## Dependencies

Canonical hashing and shared ValidationError. Evolution core/workspace adapters
own safe observation construction; evolution control owns frozen imports;
Signal evolution owns feedback/reflection integration; reflection memory and
Mining controller own bounded discovery and reads.
