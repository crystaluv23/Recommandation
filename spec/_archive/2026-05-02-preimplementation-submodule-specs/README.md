# Archived Pre-implementation Submodule Specs

## Status
Archived

These child specs were drafted before source code existed. They sketched plausible internal files such as `data/point_in_time`, `research/agents`, and `meta_learning/versions`, but most did not yet expose stable interfaces beyond their parent modules.

They are archived to keep the active architecture lean. Reintroduce any child spec only when implementation proves the submodule needs separate ownership, invariants, or tests.
