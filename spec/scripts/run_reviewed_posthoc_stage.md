# Reviewed native Posthoc stage

This independent evaluation stage reads one already durable, independently
accepted blind prediction and its exact original context. It never resumes the
parent collection budget or creates an ExecutionTrajectory, score, round pointer
or Slow source. Its acceptance oracle is frozen separately before any new answer.

Verify the completed parent manifest, full immutable checkpoint and every
request/inbox/raw/receipt/cache, including journal-only undispatched attempts.
Historical parent code is verified byte-for-byte against its exact immutable Git
commit; it need not match current label admission code. Bind all parent files
except operational locks, plus historical original/Registry/continuation files.
Reject a changed parent, partial response set, cache/receipt mismatch or missing
completion before opening labels or dispatching feedback.

Truth enters only through the strict canonical LabelStore loader after parent
verification. Freeze its manifest, records, complete archive SHA, fixed
calculator/contract and exact key. Match the saved five-date baseline and
six-calendar-month horizon. Do not transcribe a multiple, alter labels, change
the prediction or claim provider/issuer authentication from archive consistency.

Call the real LLMBlindPredictor.reflect under the existing anonymous_case
transport, with max_request_tokens=131072, one native typed correction and a new
shared ceiling of eight independent local requests. External LLM calls and new
read-only data requests are forbidden; actual host tokens/cost are unknown.
Every exact production request is answered only by a fresh isolated role. The
harness never authors feedback, alters parser results or adds missing evidence.

Retain the actual case adapter's compact context, deterministic correctness and
feedback computation, source catalog, citation-closure repair, parser and
fallback. Case reflection currently has no Plan/Round progressive read wrapper;
read_refs/browse is not an exercised or supported capability of this entry.
Do not add a wrapper to make a capability claim. Source identities, snapshots,
relations and an honest no_findings_reason remain exactly native.

Persist the exact accepted PredictionSelfReflection, usage and metadata, all
original request/response/receipt/cache artifacts and an exact request trace.
Native validation fallback is separately visible and is not semantic success.
The accepted feedback is a local diagnostic artifact, not authorized Slow input.
Completed restore verifies the frozen source/parent and complete artifact map,
all response receipts and cached original responses, with no new dispatch or
model re-execution. Keep first-answer/correction/final result accounting under
the fixed one-sample denominator. Operational progress, independent review and
execution summary are explicit sidecars outside the immutable runtime set.

The diagnostic observer records native validation/correction/mechanical/fallback
progress events without changing their payloads or the returned AgentStep.
Fallback accounting includes structured_validation_fallback_applied (including
partial salvage with a retained valid sibling and no no_findings_reason),
deterministic_fallback_promoted, the terminal validation-failure event and both
native all-invalid/terminal reason prefixes. These differ from honest empty
findings. Keep the complete event sequence and applied-event subset; derive no
research conclusion from the flags. Cache/transport billing events are separate
from this deterministic validation trace and do not replace unique receipts.
