# Independent local role stage acceptance

`prepare` freezes two original v182 Reflect inputs and five explicitly synthetic
contracts: Q2-only, public Q3 forecast, partial numeric guidance, post-cutoff
actual and terminal with no owners. The fixed denominator is seven; original
PIT pollution is not accepted as research evidence. An independent reviewer must
check semantics against frozen need, quote and permitted residual; mechanical
scope checks cannot establish semantic correctness.

`resume` invokes the production Reflect controller, parser/correction and final
context assembly, saving exact requests, raw answers and accepted/rejected
results. Each unanswered role pauses via local control flow and is dispatched
to a fresh independent subagent with only its model-facing inbox. `submit` binds
the actual spawned agent identity to the untouched raw answer. Reentering the
same logical call consumes prior bound responses and does not create another
attempt. The immutable contract permits at most 28 local calls and zero external
API calls, one native correction per invocation, 131072 conservative request
tokens and the existing per-role output limits. No old run is resumed and no
whole research cycle or provider transport is claimed.
