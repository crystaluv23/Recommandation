# Reviewed Basic Info and H_init stage

This bounded diagnostic uses the existing reviewed two-SEC snapshot and the
unchanged default InformationPlan. It follows the production bootstrap prefix:
`EvidenceResolver.resolve_basic_info(plan.basic_info_policy.requests)` →
`project_basic_info_bundle` → `LLMResearchController.initialize`. It stops after
accepted initial state and persisted projection lineage. It does not bypass
RuntimePlanEvaluator readiness, invoke Predictor, read a label, or start a full
cycle. Missing market data produces its ordinary DataGap; no anchor, price,
computed card or inherited company state is invented.

Before any role response, freeze code, both original SEC documents and reviewed
binding, Plan, two neutral sample cutoffs, role budget and a separately authored
semantic oracle. Both samples use the same issuer with cutoffs 2025-09-30 UTC
and 2025-07-01 UTC, respectively. Actual default-policy Basic Info selects the
10-Q with partial projection at the later cutoff and the 8-K with complete
projection at the earlier cutoff. Other default requests remain explicit gaps. The early request is named and
described as an annual/interim operating report, but its generic filing filter
returns an 8-K with `resolved` and no DataGap. That is a known F2 producer
fulfillment-expression failure, not a passing source-fulfillment control. Keep
this actual input to test F3 honestly: the role must identify the visible 8-K
and cannot turn the request name/status into proof of an annual/interim report.
Neither projection completeness nor a missing source proves a business fact.
Use the actual source/projection ids, available times and raw-offset lineage;
no hand-inserted text windows or expected answers enter the role payload.

Each original initialize/correction request goes through StructuredRoleClient's
independent-subagent backend, identity projection, native parser, typed repair
and fallback. Freeze one native correction per initialize call, request limit
131072 and shared local ceiling 8. External LLM and read-only data calls in this
stage are zero; socket use is forbidden. Each logical role call is delegated
fresh with only its inbox/outbox paths. Actual precise model version and
internal cost remain unknown. A pending request is control flow, not a
research failure; repeated resume revalidates originals/receipts and preserves
accepted artifacts while adding no duplicate calls.

The oracle is separate from model input. It requires useful material reasoning
from visible original disclosures with semantically faithful citations;
nonempty grounded positive work cannot be replaced by a list of unknowns.
Hypotheses must remain hypotheses; need items must request currently absent,
PIT-answerable issuer evidence rather than future facts or already visible
answers. Legal forecasts retain forecast status and source date; filing dates,
periods, units and computations cannot become invented issuer facts. Source
absence and truncated/omitted text stay bounded uncertainty. Existing runtime
validators provide mechanical checks; independent raw-material/request/raw
answer/accepted-state review provides semantic acceptance. Do not preassign a
unique thesis or force one particular next need when the original skill allows
multiple correct outputs.

Persist actual Basic Info bundle, model projection, raw-offset lineage,
initialize requests/raw answers/corrections, accepted state and exact source
bindings. Verify completed restart and binding drift rejection. The stage only
can close F3 in its frozen source/time/Plan envelope. F2 annual/interim request
fulfillment remains explicitly failed/open; it does not close the
whole source universe, Signal chain, F8/F9, feedback/Slow, full recovery or MVP.
