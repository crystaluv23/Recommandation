# Separate local-role consumer verification

Read accepted local role states through production validators, bind their saved
bytes, reconstruct actual state deltas, and assemble production final context,
posthoc and critic projections. Verify exact disposition identity through all
three projections and persistence/reload. This is new local consumer evidence
with its own code identity, never a rewrite of the source batch's failure,
frozen code, raw answer or outcome. Critic construction retains explicitly
historical predictions/labels only as its required input shell; no new
prediction, posthoc, critic model or source acquisition is executed. Independent
semantic review remains required and no whole-MVP closure is inferred.
