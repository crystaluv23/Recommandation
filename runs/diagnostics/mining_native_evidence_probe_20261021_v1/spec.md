# One bounded native Mining evidence probe

Only prepare this script/plan now. Root independently freezes exact code,
source/expectation files and revision, then authorizes its sole execution.
Products and all completed stages remain unchanged. The initial broader draft
is preserved under driver/; the actual scope is the seven frozen oracle controls.

Inputs are oracle/exact-inputs.json and its pre-execution source expectations,
including the exact four original0671 whole spans and six independently authored
synthetic documents. No real value key is renamed to val. The synthetic dual-key
fixture is an explicit isolated branch bypass, not evidence real typed originals
produced a wrong pair. Approved dev8 metadata supplies only case008's company and
cutoff here: a SimpleNamespace adapts exactly case_id/company_id/prediction_time.
This is not an EvolutionCase/Engine reconstruction; no outcomes/check labels,
approved40 mixed envelope or LabelStore are read. Real O1 fetch uses the actual
qualified1780 reviewed store; synthetic P1 uses a disclosed documents-only
in-memory collection, never source append or admission.

The exact seven controls, with no expanding scan, are:

- O1: native fetch_case_evidence, original case008, sec_company_facts, no query,
  cap1. Record complete native candidate/order/selected/excluded and availability.
- O2: native _company_facts_context then project_facts_from_documents on unchanged
  exact original0671. Bind selected-vs-direct identity explicitly. Save context
  records/literals/offsets/partial/omissions before interpreting EvidenceFact0.
  Empty context is an earlier gate, not automatically a value/val diagnosis.
- L1: synthetic legacy-val positive, native fact projection/relations, then
  compute_statistic ratio and difference using only actual native relation refs.
- T1: small synthetic typed value-only context/facts adaptation control.
- R1: synthetic typed dual-key alternative/duration/unit control. Preserve all
  exact context rows/facts and native builder operands, including conflicts.
  Compute ratio/difference only for actual builder-selected pairs, including
  EUR's independent pair. Generic numeric acceptance across units/durations is
  arithmetic observation, not automatic policy failure or economic comparability.
- P1: older/newer/future synthetic documents; native no-query and exact
  "Operating Cash Flow" query tie at cap1, with PIT and cap exclusions separate.
- P2: synthetic typed future-end/future-filed rows, checking native context PIT
  separately from its value-only adapter failure.

No hand-authored EvidenceFact or substituted oracle operand reaches a helper.
No numeric result is calculated except the explicitly frozen deterministic
compute_statistic controls; these are Evidence Graph tool calls, not Signals.
No new comparison policy is inferred. Every native output/exception and actual
first frontier is retained; neither assertions nor expectations are adjusted to
make the diagnostic pass. No model, candidate or subsequent stage is started.

Execution validates root-supplied revision, exact plan/script hashes and all
source/code bytes before an exclusive execution marker. One run saves the seven
observations and source/code before/after bindings and seals the first terminal.
Any completed/failed/partial execution forbids reentry or retry. Failure is
preserved, not a license to fix-and-rerun or expand the seven controls.

Only the new execution directory is writable. Network/HTTP, model calls,
Signals, Registry freeze/audit, persistent RawInfoStore construction/append,
LabelStore, LockedTest and full execution are forbidden. Empty in-memory parent
RawInfoStore initialization is allowed only for the real reviewed subclass.
Source bytes and their PIT scope remain unchanged. Administrative exit0 or
hash equality cannot establish semantic Mining progress or new capability.
