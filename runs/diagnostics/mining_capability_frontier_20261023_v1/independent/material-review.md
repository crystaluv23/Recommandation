# Independent material/definition review

This is a private, bounded source oracle for prospective S3–S8 engineering capability controls. It creates no candidate, Signal, predicate specification, production answer or experiment advancement. This review used the existing independent reviewer; no fresh production role, further actor, network, external API, business-label store, check case or Locked Test was used. The only group map is the original native wire's opaque dev8 map. Outcome differences were not used to select or score measurements. Host reviewer tokens/fees were not measured; provider GET and external LLM API calls are zero.

`material-obligations-frozen.json` was written before the conclusions below. It binds the original static inventory, original `first_native_manifest_wire`, reviewed1780 snapshot, eight authorized case IDs/cutoffs, all 263 corresponding original source documents and the exact stable18 specs. All original document/content hashes and all stable spec hashes matched at freeze. The selected documents comprise 240 company-facts documents, 14 narrative filings and nine market documents. Each selected document's recorded availability is within its own case cutoff; that is a necessary source gate, not independent proof of historical body truth. Company-facts retain `requires_primary_filing_audit` and retrospective extraction qualifications.

## Result

There are two materially supported prospective capability paths, subject to distinct limitations. First, the existing price-momentum callable genuinely supports a different supplied-observation window; changing that window changes operands and measurement, whereas changing classification thresholds alone does not. Second, explicit management conclusions about ICFR material weaknesses are a clean narrative family separate from the six stable narrative skills. Neither path has been mined, implemented, admitted, reused or effect-validated here. The parent review owns whether their evidence can survive the current Mining→S5 interface and full request costs.

There is also an exact structured-financial capability gap: source-supported new concept combinations exist, but no registered financial callable implements arbitrary new concept ratios or formulas. A source-supported financial family must not be passed to an unrelated function or recast as an LLM judgment merely to avoid this limitation.

## Narrative support, clean distinctions and counterexamples

`narrative-material-bindings.json` retains complete original raw paragraphs, coordinates, hashes, readable renderings and filing URLs:

- case-005 document1507 `[2334869,2336241)` explicitly reports management's ICFR conclusion for March31 2025: not effective due to a material weakness in complex-financial-instrument accounting/presentation. `[2336241,2337349)` explicitly reports nonremediation and proposed future steps. Availability2025-05-20 precedes cutoff2025-05-30. Actual assessment and proposed remediation must remain separate.
- case-006 document1500 `[933913,934606)` explicitly states that the company's assessment as of December31 2024 determined no control deficiencies constituting material weaknesses. Availability2025-04-22 precedes cutoff2025-07-31. This is source-supported contrary evidence to an actual material-weakness conclusion, without inferring stock direction.
- case-003 document1501 `[478218,478843)` says it *may experience* material weaknesses. That is hypothetical risk, not an actual identified weakness. A lexical hit is a counterexample to the semantic predicate.
- case-001 document1768 has source passages saying six significant deficiencies and then “identified material weaknesses”; other passages report effective disclosure controls or omit a management ICFR assessment under transition rules. These are retained as terminology/object/assessment-scope ambiguity. They must not become an automatic clean positive or clean negative.

An explicit, dated management ICFR conclusion is a semantically clean new narrative object when the actual assessment is present. It is distinct from disclosure-controls effectiveness, a significant deficiency, an auditor opinion, a future possibility, generic statutory boilerplate and a financing action. The finite source review does not establish that every dev case is answerable or that missing mentions prove absence. The family can support prospective actual/hypothetical/contrary/ambiguous material controls; it does not establish directional or magnitude relevance to the fixed stock target.
