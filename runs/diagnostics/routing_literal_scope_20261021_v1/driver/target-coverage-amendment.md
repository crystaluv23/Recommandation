The literal partition proof must match each **complete target side**, not merely
show reason/residual disjointness. Target `within180` / `before that180` cannot be
answered by reason `within90` plus residual `before180`: days90..180 were lost.
Likewise target Jan1..May30 / beforeJan1 cannot be answered by May1..May30 /
beforeJan1. Preserve exact interval endpoints, lengths, anchor identity and
inclusion/exclusion relation from the target, and reject omitted middle ranges.
No date arithmetic is needed for exact same-window anaphora; explicit calendar
forms need parsed dates and exact target-side coverage as well as nonoverlap.

Object proof concerns only explicit target syntax. It cannot prove issuer aliases
or equate different names semantically. Full ordered object matching and the
current whole-word/one-modifier safeguards remain necessary.

This amendment adds a proposed acceptance invariant, without another execution
or production edit. Existing proposal/result/bindings bytes are unchanged.
