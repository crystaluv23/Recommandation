## Minimum internal proof, shared by the two route gates

Add one private, bounded literal proof in the existing validation module; no
canonical field, public interface, research definition or PIT policy changes.
It returns proof only for a whole asserted claim partition, never merely because
some word differs. Route computes it once from exact target, reason and residual
and uses the same result before (1) cosmetic-residual rejection and (2) shared
phrase rejection. Existing future-cutoff, grounding, eligibility and other gates
remain independently active. Leave `_coordinated_residual_facet_terms` unchanged.

Support only two independently checkable literal constructions initially:

1. **Repeated facet, distinct explicit objects.** The target itself must expose
   coordinated complete arms containing the same ordered multiword facet and
   different complete object spans. The reason must assert only the answered
   object+facet arm; residual must explicitly retain the other object+facet arm.
   Matching uses whole-token boundaries and full ordered spans, not proper-name
   recognition or a product dictionary. Shared words alone, partial object names,
   missing object anchors, or a second claim of the retained arm cannot prove a
   partition. Do not infer ownership from a general prefix removal.

2. **Same facet/object, complementary disclosure windows.** The target must
   literally establish a single window and its strict `before that window`
   counterpart. Bind each qualifier to the actual disclosure claim in its own
   clause. Reason must use the within-window claim and residual the before-window
   claim, with the same explicit window reference (or uniquely resolved `that
   window`). This does not mean that unequal lengths are disjoint: 180 and 90
   days overlap. Missing/ambiguous antecedent, overlap, negated scope, a qualifier
   attached to a different fact/sentence, or a reason also claiming the retained
   window gives no exemption. Preserve prediction-time upper bounds independently.

A separate explicit calendar interval construction, if implemented, must prove
actual parsed-date nonoverlap and endpoint ownership. It must not be obtained by
relaxing token overlap or assuming different dates imply different scopes. Root's
independent Jan1..May30 / beforeJan1 case shows why route cosmetic and overlap
must consume one proof. This case is not part of this driver's 11 executed cases.
Any unsupported date/window syntax remains conservative, with its frontier named.

Do not exempt an entire multi-sentence reason after finding one valid scoped
claim. An additional retained-arm claim still invalidates ownership. If bounded
literal association cannot establish which facet a qualifier modifies, return
unknown/no proof; do not infer it semantically or delete words until a case passes.

## Actual successor frontier and minimum permission boundary

Routing order is: residual grounding/cutoff checks, cosmetic test around
`evolution_plan_roles.py:1321`, typed cosmetic issue at1478, coordinated conflict
at1526, shared phrase at1566, then typed correction and existing fallback.
Thus changing `_shared_distinctive_phrase` alone cannot repair earlier cosmetic
rejections. Root's independently observed explicit-date case confirms this.

F7 has separate checks: `validate_need_dispositions` at validation2506,
`_validate_research_state_refs` in the output consumer, and targeted transition /
cosmetic restoration at validation4102..4139. A routing-only repair cannot be
called an end-to-end residual-consumption repair.

For those consumers, the smallest safe exception is **an actual adopted,
available partial owner and its exact residual mirror**, with existing evidence
tuple/PIT validation still passing. Reuse that owner's literal partition proof;
do not grant generic near-duplicate rewrite permission based on two strings alone.
An unanswered disposition, absent batch, nonadopted/invalid tuple, untargeted need,
or changed residual must keep existing occurrence-aware preservation rules. Scope
proof does not manufacture evidence that a result answered the facet. If caller
context cannot establish this actual ownership, leave the downstream gate closed
and report that frontier instead of expanding it.

Proposed verification: both frozen positives; the nine paired negatives here;
existing shared-prefix, shortened-head typed two-answer attacks, one-modifier,
whole-word, temporal/cosmetic cases; explicit calendar partition plus overlap and
endpoint controls; and a native validated partial owner→exact residual consumer
positive paired with unanswered/no-batch/wrong-owner/changed-residual negatives.
No model/stage rerun follows merely from these offline tests.

## Judgment

Both observed false rejections are caused by losing literal scope before generic
overlap comparison. Their bounded literal constructions can be addressed without
new economic/PIT/canonical policy. A general NLP parser, brand classifier or new
LLM judge is neither justified nor proposed. Ambiguous attachment, omitted object
or window, nonliteral paraphrases, arbitrary date grammar, and ungrounded actual
answer ownership remain unknown. Original GPRE portfolio strict0/1 and all sealed
answers, budgets and results remain unchanged.
