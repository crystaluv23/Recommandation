# Additive Reflection in Fixed FIFO Meta-Info

visit_times: 1

## Trigger

Read this before changing case self-reflection, Plan criticism, Round reflection,
or the Information Plan proposer's FIFO meta-info payload.

## Lesson

Reflection layers must add information without replacing earlier evidence. One
committed round entry retains the original anonymous post-hoc case reflections,
then the exact vertical Plan-critic output and deterministic parent comparisons,
then horizontal cross-child Round insight. `PlanMetaMemory` remains one bounded
append-only FIFO; capacity eviction removes the oldest whole round entry.

## Context

A real parent-to-child regression correctly exposed that annual-filing and
financial-fact requests had been removed, but successive Plan and Round
summaries reduced the evidence to a generic data-availability lesson. The next
proposer therefore lost the specific, testable action to restore those requests.

The correction persists the exact reflection layers rather than asking a later
LLM to reproduce them. The proposer may use the committed outcome-aware memory,
but blind Plan execution and prediction never receive it. The persisted layer
uses opaque within-Plan case indexes and excludes company/case ids, Raw Info,
literal evidence, and research contexts.

## How to Apply

- Build original case reflection records deterministically from immutable saved
  predictions, truth-derived four-way feedback, and post-hoc reflection.
- Let the Plan critic author only vertical cross-case and parent-child insight.
- Let the Round reflector author only horizontal cross-child insight.
- Compose all layers locally after the Round call, persist one entry, commit the
  round, then append that whole entry to the existing FIFO.
- Keep legacy horizontal-only entries readable and never let reflection change
  predictions, labels, Binary F1, Top-K, or Signal state.

## Limits

FIFO length bounds the number of rounds, not the byte size of one reflection
entry. If prompt size later becomes a problem, change the explicitly approved
memory contract rather than silently summarizing or dropping an earlier layer.
