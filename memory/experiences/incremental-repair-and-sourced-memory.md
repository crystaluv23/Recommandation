# Incremental Repair and Sourced Reflection Memory

visit_times: 57

## Trigger

Changing research-state correction, reflection schemas, prompts, source indexes,
or any Fast/Slow consumer of accumulated experience.

## Lesson

Before blaming instruction following, prove that the initial prompt exposes the
validator's requirements, the model can see the necessary evidence, the rules
are mutually compatible, and repair permissions admit the requested solution.
Correction prose is not authority. Bind local edits to the exact prior snapshot
and typed field permissions; preserve valid siblings and fully validate the
assembled result. Do not broaden a missing-field add into permission to append
unrelated rows. Control-plane failures must propagate, not become model mistakes.

Full immutable history and bounded model context are separate contracts. Produce
structured detail and an actionable brief together. Preserve conditions, concrete
research action and material caveats; reference membership proves provenance,
not semantic truth. Higher layers select valuable lower items by stable identity
or add explicitly sourced hypotheses. A correct prediction does not oblige the
model to invent a causal explanation. Technical reflection failures must not
become research lessons. Empty supported findings need an explicit reason.

## Context

The September 2026 retrospective found incomplete initial contracts, impossible
repair permissions and repeated whole-state output. Large inputs came from a
few full-history entries, not merely too many rounds. During the 2026-09-28
repair, shortening proposer briefs initially left Plan critic trajectories and
source catalogs at hundreds of kilobytes. A paginated directory also made case
examples unreachable within the read budget because all early pages were higher
levels. Tests of individual view helpers had not covered either composition.

## How to Apply

- Replay frozen real requests at the owning production adapter before adding a
  guard. Verify initial instructions, local repair, preserved valid components,
  complete revalidation and subsequent consumer behavior together.
- Keep canonical source shapes identical at generation, archive composition,
  restart and rebase. Bind case identity to its immutable anonymous input and
  prediction, not just outcome facts shared by unrelated cases.
- Reconstructing a legacy source cannot append newly derived optional diagnostics:
  whole-source hashes and fallback case identities may already be cited by saved
  Plan/round items. Preserve the old producer's recorded shape; only saved modern
  status-bearing context authorizes its matching diagnostic projection. Verify
  real saved Plan construction and subsequent source reads, not only case views.
- Measure the actual composed request at every consumer. Count catalogs,
  diagnostics and disclosure envelopes as well as brief text. Bound complete
  units; never silently clip originals or enumerate unlimited deferred IDs.
- Make lower-level examples discoverable within the finite read budget. Expose
  layer browsing and whole-unit read sizes; ensure every advertised handle is
  actually readable through the production resolver.
- A reserved identifier slot is not evidence: references must resolve to an
  actually produced item. New lessons cannot support themselves or each other
  without lower-level evidence. Check the live parser and persisted graph at
  the same boundary so storage does not reject a supposedly accepted response.
- Audit Fast memory forwarded into Slow consumers as well as each loop's own
  memory. An archive serialization helper with a model-facing name can silently
  reintroduce full replay through a second consumer; give archival and bounded
  APIs distinct names and test that production path.
- Exercise case to Plan to Round to persistence to next-proposer consumption,
  plus Slow reflection to method view to original-source reading. Keep outcome
  memory outside blind execution and prediction.
- Preserve legacy originals with explicit unreviewed status. Test fixture
  translations are offline adapters, never production compatibility that lets
  a live model bypass the new protocol.

- Whole-JSON citation equality needs duplicate-key and type checks; ordinary
  JSON decoding silently hid repeated `fy` keys in real Update outputs. Restore
  only a unique complete original in the same case/document scope, never a
  subset that requires invented fields. Keep unrelated semantic/fixture failures.
- Typed corrections need existing coordinates: missing rows grant bounded append
  on the existing array, not authority over a future index. Validate raw member
  types before legacy canonical readers can drop rows and shift patch indices.
  A false sole gap may require explicit replace-only verdict dependency; never
  force another invented gap just to satisfy preservation.

- Blindness requires testing actual outgoing prose, not only ticker fields, URL
  and XBRL handles. A short brand derived from an all-caps legal name can be
  mistaken for a case-sensitive ticker; preserve the provenance of derived
  name matching and verify estimation, wire, inverse restoration and source
  immutability together.

## Limits

Offline replay proves protocol, identity, preservation, sizing and wiring.
Scripted new-format reflections do not prove better model compliance, useful
briefs, fewer real corrections or research gain. Those require separately
authorized live validation and independent paired evaluation. Do not turn Jev
or another model's confidence into a probability that a lesson is true.
